# IdolRadar 首批 idol 总榜

本文档是唯一的候选名单，此前两份初筛文档（微博粉丝榜、五维加权榜）中出现过的每一位 idol 都在本文档内，分入选池与落选池。

## 一、评分口径

**五维加权分**（第一榜池排序用，满分 75）：更新频率×5、平台账号数×4（仅官方，有海外平台加分）、动态质量×3（广告与转发算低质）、粉丝基数×2（以微博为主）、粉丝年龄×1（越小越好）。每维 1–5 分。

**三维分**（第二榜池筛选用，满分 15，等权）：粉丝基数、粉丝年龄（越小越好）、本人年龄（越小越好）。

- 粉丝基数：5=破亿，4=7000 万以上，3=5000 万以上，2=3000 万以上，1=3000 万以下。
- 粉丝年龄：5=主力 18 岁以下，4=18–24，3=25–30，2=30–35，1=35 以上。
- 本人年龄：5=2000 年后出生，4=1995–99，3=1990–94，2=1985–89，1=1985 前。

**斩杀线**：更新频率 ≤2 分（约低于每月两条原创）直接出局，不论粉丝量多高、不论进的是哪个池子。理由是用户守护后只会看到一潭死水，产品侧等于空壳。

**入池规则**：第一榜池 = 原五维主榜 + 本轮新增热点（微博榜 A 组 26 人已被五维主榜完全覆盖，无遗漏）。第二榜池 = 微博榜 B 组去掉已进第一榜者 + 运动员组，按三维分 ≥9 晋级。
