# IdolRadar 首批 idol 总榜

本文档是唯一的候选名单，此前两份初筛文档（微博粉丝榜、五维加权榜）中出现过的每一位 idol 都在本文档内，分入选池与落选池。

## 一、评分口径

**五维加权分**（满分 75）：更新频率×5、平台账号数×4（仅官方，有海外平台加分）、动态质量×3（广告与转发算低质）、粉丝基数×2（以微博为主）、粉丝年龄×1（越小越好）。每维 1–5 分。

**微博 A 榜加成 +10**：初筛微博榜 A 组的 26 人（2026 当红一线）享有 +10 加成，量级等同粉丝基数一维的满分权重。A 榜成员**保送第一榜池**，不参与第二榜池的三维筛选；加成只影响池内排序，不影响是否入选。

**三维分**（第二榜池筛选用，满分 15，等权）：粉丝基数、粉丝年龄（越小越好）、本人年龄（越小越好）。

- 粉丝基数：5=破亿，4=7000 万以上，3=5000 万以上，2=3000 万以上，1=3000 万以下。
- 粉丝年龄：5=主力 18 岁以下，4=18–24，3=25–30，2=30–35，1=35 以上。
- 本人年龄：5=2000 年后出生，4=1995–99，3=1990–94，2=1985–89，1=1985 前。

**斩杀线**：更新频率 ≤2 分（约低于每月两条原创）直接出局，不论粉丝量多高、不论是否 A 榜、不论进的是哪个池子。**这是唯一能淘汰 A 榜成员的规则**。理由是用户守护后只会看到一潭死水，产品侧等于空壳。

**入池规则**：第一榜池 = 微博 A 榜 26 人（保送）+ 原五维主榜其余成员 + 本轮新增热点。第二榜池 = 微博榜 B 组去掉已进第一榜者 + 运动员组，按三维分 ≥9 晋级。
