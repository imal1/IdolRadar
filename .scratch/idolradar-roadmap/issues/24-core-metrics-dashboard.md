# 24 — 核心指标面板

**What to build:** 管理员能看到 PRD 定义的两个转化类成功指标：新用户中完成「选 idol 加授权」的闭环转化率，以及收到推送后的回访率。

这两个指标全部从服务端既有业务数据计算，不依赖任何前端埋点，因此天然跨端——未来 app 客户端接入后无需重复实现。前端行为漏斗（页面停留、点击分布）是另一件事，交给各端平台自带的分析能力。

**Blocked by:** 05 — 管理端身份与访问控制；08 — 推送回访上报（服务端）

**Status:** ready-for-agent

- [ ] 展示闭环转化率，并能看出用户在哪一步流失
- [ ] 展示推送回访率
- [ ] 可按时间区间查看趋势
- [ ] 指标口径与 PRD 成功指标一致，并在页面上写明口径
- [ ] 页面受管理端鉴权保护
