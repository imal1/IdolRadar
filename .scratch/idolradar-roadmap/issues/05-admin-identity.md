# 05 — 管理端身份与访问控制

**What to build:** 一套独立于用户会话的管理员身份，使得后续所有管理端页面有一个可依赖的登录与鉴权基础。

目前后端只有一种身份：微信静默登录得到的 openid 会话。管理端的每一块功能都需要一个不同的、权限更高的身份，这是整个运营能力方向唯一的硬前置。

这是安全边界，不要用「openid 白名单」凑合——那等于把后台权限绑定在一个微信号上，无法回收、无法审计、无法多人协作。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 管理员身份与用户会话完全隔离，互不能提权
- [ ] 管理端路由整体受鉴权保护，未认证请求不泄露任何业务数据
- [ ] 凭据不入库明文，不写进代码库
- [ ] 支持吊销某个管理员的访问
- [ ] 管理端的写操作留下可追溯的操作记录
- [ ] 鉴权失败与越权访问有测试覆盖
