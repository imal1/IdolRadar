# 09 — 抓取源健康度看板

**What to build:** 管理员能在一个页面上看到所有抓取源的健康状况——哪个源在正常工作、哪个源连续失败、最后一次成功是什么时候、失败原因是什么。

每个源的抓取状态、最后抓取时间、错误码、条目数量都已经在每轮抓取时写入数据库，但没有任何对外出口，只有直连数据库才看得到。当源的数量从一个增长到多个之后，某个源静默失败三天而无人察觉是最可能先发生的事故。

**Blocked by:** 05 — 管理端身份与访问控制

**Status:** ready-for-agent

- [ ] 列出全部源及其最近一次抓取的状态、时间、错误码、入库条目数
- [ ] 失败与长时间未成功的源在视觉上可被一眼识别
- [ ] 可按 idol 或状态筛选
- [ ] 页面数据反映最近一轮抓取的真实结果，不使用缓存导致的滞后
- [ ] 页面受管理端鉴权保护
