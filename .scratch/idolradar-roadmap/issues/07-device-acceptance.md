# 07 — 真机端到端闭环验收

**What to build:** 在真实设备与真实微信环境中，完整走通 PRD 定义的 MVP 五步闭环，并确认每一步的实际表现与设计一致。

MVP 的代码已全部实现，但从未在真机上完整跑通过。真机环境会暴露一批只在真实条件下才出现的问题：订阅消息的实际到达率与延迟、RSS 源在生产网络下的稳定性、推送落地页在冷启动与热启动下的定位差异。

**Blocked by:** 01 — 申请订阅消息模板并接通生产链路

**Status:** ready-for-agent

- [ ] 全新用户首次打开即可使用，无任何注册步骤
- [ ] 从 idol 库选择并守护一位，返回雷达首页看到该 idol
- [ ] 完成订阅授权，蹲守提醒 banner 相应隐藏
- [ ] 新动态入库后收到微信订阅消息，端到端耗时在 PRD 要求的时限内
- [ ] 点击推送落到雷达首页并定位到对应动态，冷启动与热启动都验证
