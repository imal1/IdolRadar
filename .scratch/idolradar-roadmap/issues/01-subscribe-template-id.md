# 01 — 申请订阅消息模板并接通生产链路

**What to build:** 用户完成订阅授权后，云端抓到新动态时能真实收到微信订阅消息，点击后落到雷达首页并定位到那条动态。目前推送链路的代码全部就位，但用的是占位模板 ID，从未在真实微信环境发出过一条消息——这是 MVP 五步闭环中唯一没有在生产环境验证过的一段。

对应 PRD 开放问题 #1。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 在微信公众平台申请订阅消息模板，确定模板 ID 与字段名（idol 名、动态标题、时间）
- [ ] 模板字段与推送内容组装逻辑对齐，字段长度超限时有截断策略
- [ ] 生产环境配置真实模板 ID，且模板 ID 不硬编码在代码里
- [ ] 在真实微信环境成功发出一条订阅消息并被点击打开
- [ ] 点击后落地页正确定位到消息对应的那条动态
