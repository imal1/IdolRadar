# 21 — 推送投递看板

**What to build:** 管理员能看到推送的投递情况——发出去多少、失败多少、失败原因分布、待发队列是否积压、重试是否卡住。

投递账本与待发队列的状态数据已经完整落库，包含尝试次数、下次重试时间、额度预占等字段，但没有任何查询出口。推送是这个产品的核心动作，它静默失败时你会是最后一个知道的人。

**Blocked by:** 05 — 管理端身份与访问控制

**Status:** ready-for-agent

- [ ] 展示投递状态分布与失败原因分布
- [ ] 展示待发队列的积压量与最久等待时间
- [ ] 可识别出反复重试未成功的投递
- [ ] 可按时间区间与 idol 筛选
- [ ] 页面受管理端鉴权保护
