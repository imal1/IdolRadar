# 14 — 用户可屏蔽指定源的推送

**What to build:** 用户可以关掉某个源的消息，关掉之后不再收到该源内容的推送；未做任何设置的用户默认收到全部源。

存储上记录「被关掉的」而非「已订阅的」：默认全收符合「守护一位 idol 就是想知道她的全部动态」这一语义，新增源自动对所有人生效，无需为每个用户补写订阅记录，数据量也只有实际关闭过的那几行。

**Blocked by:** 13 — 源增加人类可读的展示名

**Status:** ready-for-agent

- [ ] 用户可以关闭和重新开启指定源
- [ ] 被关闭源的新动态不再向该用户推送
- [ ] 未做任何设置的用户行为与当前完全一致
- [ ] 新增源默认对所有用户生效，无需回填
- [ ] 更换守护对象后，屏蔽设置的处理方式明确并有测试覆盖
- [ ] 推送目标筛选在加入该过滤后仍能走索引，不引入全表扫描
