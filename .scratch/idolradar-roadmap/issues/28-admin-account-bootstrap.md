# 28 — 生产首个管理员账号与凭据轮换

**What to build:** 一条可重复执行的流程，让生产环境产生第一个管理员账号，并说明口令如何轮换。

ticket 05 建立了管理员身份、会话与吊销，但没有回答「生产上第一个账号从哪来」：seed 不写 `idr_admin_account`，compose 里只有会话 TTL。也就是说管理端现在**部署上去也登不进去**。

仓库已经有 `migrate` 与 `seed` 两个一次性 compose 服务的先例，bootstrap 沿用同一模式，运维不需要学新东西。幂等是硬要求：重复执行不能覆盖已存在的管理员，否则一次误操作就会把线上凭据换掉。

只做 bootstrap 与轮换手册，不做管理员管理 UI——现在还不存在第二个管理员，上 UI 就要连带定义权限模型，那是独立方向。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 一次性 `admin-bootstrap` compose 服务，手动触发，不随常驻服务启动
- [ ] 幂等：已存在管理员时不创建、不覆盖，重复执行安全
- [ ] 凭据不入库明文、不写进代码库，创建后明确提示从 `.env` 移除
- [ ] 文档写清首次部署步骤与口令轮换步骤，以及轮换后如何吊销旧会话
