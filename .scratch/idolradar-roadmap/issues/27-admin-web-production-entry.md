# 27 — 管理端生产入口：访问控制、安全响应头与静态资源缓存

**What to build:** 一份可套用的宿主机 Nginx 配置范本，定义管理端在公网上的入口行为：访问路径、安全响应头、静态资源缓存策略。

管理端页面现在没有任何安全响应头——没有 CSP、没有 X-Frame-Options、没有 Referrer-Policy、没有 noindex。一个能改 idol、改抓取源、看投递账本的后台以这个状态暴露在公网上，是目前最直接的风险敞口。

同时，Vite 产物带文件名指纹而 `index.html` 不带，缓存策略必须区分对待：指纹资源长缓存、入口 HTML 不缓存。缓存错了会出现「新 JS 配旧 HTML」或反过来的错配，症状是发版后管理端间歇性白屏或调用不存在的接口。

宿主机 Nginx 不由本仓库部署，所以交付物是**范本 + 套用文档**，文件头必须写明这一点。CSP 这类逐字精确的配置写成散文没人 diff 得动，因此以配置文件形式进仓库。

访问控制这一版只做应用层登录 + 安全响应头，不加 IP allowlist：管理员没有固定出口 IP，allowlist 会立刻退化成一个天天要开的临时口子。日后需要时再加是一行配置。
