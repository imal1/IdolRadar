# 02 — 定死「信号强度」与「今日动态」的统计口径

**What to build:** 雷达首页头部统计行的三个数字有明确且写下来的定义，前后端对同一个词的理解一致。

目前「信号强度」的实现是「有源就满格、没源就无信号」，本质是装饰性文案；「今日动态」的「今日」按哪个时区的自然日切分也没有写下来。这两个数字会出现在用户第一眼看到的位置，口径含糊会在有真实用户之后变成客服问题，也会让后续的指标面板无法对账。

对应 PRD 开放问题 #2。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 明确「信号强度」是装饰性文案还是真实指标；若是装饰性，在 PRD 与代码注释中写明，避免后人误当指标使用
- [ ] 若为真实指标，给出计算式（例如启用源占比、近 N 轮抓取成功率）并实现
- [ ] 明确「今日」的时区与切分时刻，并在实现中固定下来
- [ ] PRD 开放问题 #2 从「待定」改为已决议，记录结论
