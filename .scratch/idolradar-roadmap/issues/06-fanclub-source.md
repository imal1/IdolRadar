# 06 — 接入粉丝组（后援会）动态源

**What to build:** 用户守护一位 idol 后，动态流里同时出现该 idol 后援会账号发布的内容，带有可辨识的来源标签。

粉丝组在各平台通常有自己的可关注账号，其内容（应援、打投、行程整理）往往是核心粉丝最想要的信息。数据模型上，一个 idol 已经支持挂多个源，粉丝组账号就是其中一条——抓取、去重、推送、动态流都是按 idol 聚合的，不关心源属于谁，因此这个功能不需要改动后端代码。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 确定当前 seed 中 idol 的后援会账号，补充为一条新的源记录
- [ ] 该源的渠道标签在动态流中可与 idol 本人的内容区分开
- [ ] 抓取一轮后，粉丝组内容正常入库并出现在动态流中
- [ ] 粉丝组的新动态能正常触发推送，与本人动态走同一条链路
- [ ] 确认粉丝组与 idol 本人在同一平台时不会互相干扰去重
